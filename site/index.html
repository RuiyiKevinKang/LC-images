DATA GUIDE

从你已有的数据开始。

XLSX / CSV / TSV

推荐使用带坐标的长表，每一行是一帧中的一个网格。

t,x,y,G
0,0,0,121.5
0,16,0,118.2
1,0,0,123.0
1,16,0,119.1

P 文件将最后一列改为 P。每帧坐标须完整、固定且不重复。XLSX 首个工作表为数据，另可用 metadata 表声明面积等信息。

JSON / NPY / NPZ

适合已有实验流程与较大的数组。

G: (T,H,W) 或 (T,N) + xy
P: (T,H,W) 或 (T,K)
time: (T,) 可选
mean_green: (T,B) 已分箱

NPY 的 G 按图像序列解释。JSON / NPZ 可携带 time、xy、cell_area、kind 与多组视频。无时间时按帧索引处理。
